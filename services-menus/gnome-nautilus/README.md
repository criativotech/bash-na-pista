# ⛵ Service Menus para GNOME Nautilus

Coleção de extensões e menus de contexto (Service Menus) para o gerenciador de arquivos **Nautilus** (Gnome), focados em produtividade e automação de mídia.

---

## 🛠️ Repositórios e Ações Disponíveis


### 🖼️ [superconverter](https://github.com/criativotech/superconverter)
* **Descrição:** Converte imagens entre diferentes formatos (PNG, JPG, WEBP) diretamente pelo menu de contexto do Nautilus.

---

## 🚀 Como Instalar

1. Acesse o repositório do projeto desejado nos links acima.
2. Siga as instruções do `README.md` específico de cada repositório para instalação.
