# 🐬 Service Menus para KDE Dolphin

Coleção de extensões e menus de contexto (Service Menus) para o gerenciador de arquivos **Dolphin** (KDE Plasma), focados em produtividade e automação de mídia.

---

## 🛠️ Repositórios e Ações Disponíveis

### 🎨 [SVGcoloring](https://github.com/criativotech/SVGcoloring)
* **Descrição:** Menu de serviço para alteração e troca rápida de cores diretamente em arquivos `.svg`.
* **Uso:** Clique com o botão direito em um arquivo `.svg` > **Actions** > **SVGcoloring**.

---

### 🖼️ [image-converter](https://github.com/criativotech/image-converter)
* **Descrição:** Converte imagens entre diferentes formatos (PNG, JPG, WEBP) diretamente pelo menu de contexto do Dolphin.
* **Uso:** Clique com o botão direito na imagem > **Actions** > **Convert Image**.

---

## 🚀 Como Instalar

1. Acesse o repositório do projeto desejado nos links acima.
2. Siga as instruções do `README.md` específico de cada repositório para a instalação.
