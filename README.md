## 📌 Sobre este Repositório
Este repositório contém todos os **scripts, dotfiles, templates de Inkscape/GIMP e configurações** apresentados nos vídeos do canal **BASH NA PISTA**.

---

## 🛠️ Stack Criativa & Terminal

- **Sistema Base:** Linux
- **Suíte Visual:** Inkscape, GIMP, Kdenlive, Blender
- **Automação:** Bash, ImageMagick, FFmpeg

---

## 📂 Estrutura de Pastas

```text
.
├── scripts/             # Scripts Shell de automação e workflow
├── dotfiles/            # Configurações de terminal, prompt e RICE
├── services-menus/      # Menus interativos de contexto para gerenciadores de arquivos
│   ├── plasma-dolphin/  # Extensões e ações para o KDE Dolphin
│   └── gnome-nautilus/  # Extensões e ações para o GNOME Nautilus
├── templates/           # Assets vetoriais (.svg) e presets de design
└── README.md
```

## 🚀 Como Usar os Scripts

1. Clone o repositório:
    
    Bash
    
    ```
    git clone [https://github.com/criativotech/bash-na-pista.git](https://github.com/criativotech/bash-na-pista.git)
    cd bash-na-pista
    ```
    
2. Dê permissão de execução para os scripts:
    
    Bash
    
    ```
    chmod +x scripts/*.sh
    ```
